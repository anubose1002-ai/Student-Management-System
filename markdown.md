# Student Management System

## 📌 Overview

A simple web-based **Student Management System** for managing student records, marks, subjects, and attendance.

## ✨ Features

- Student registration and management
- Add, edit, view, and delete students
- Subject management
- Marks and grade management
- Attendance tracking
- Student search
- Dashboard

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache / XAMPP
- **Version Control:** Git & GitHub

## 📂 Main Modules

```text
Student Management
├── Students
├── Subjects
├── Marks
├── Attendance
└── Dashboard
```

## 🎯 Objective

To provide a simple and efficient digital system for managing student academic and personal records.
